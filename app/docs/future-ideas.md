# AURA — Ideas futuras

Este documento contiene ideas que podrían aportar valor a AURA, pero que no pertenecen necesariamente al MVP.

Una idea incluida aquí no representa un compromiso de implementación.

## Motor de decisiones

AURA podría responder:

- ¿Qué hago ahora?
- ¿Qué debería posponer?
- ¿Qué compromiso debería rechazar?
- ¿Qué estoy sacrificando?
- ¿Cómo afectará esta decisión a mis próximas semanas?

## Simulador de escenarios

Permitir preguntas como:

- ¿Qué pasa si acepto otro cliente?
- ¿Qué pasa si adelanto este proyecto?
- ¿Qué pasa si tomo una semana libre?
- ¿Qué pasa si reduzco mi jornada?

Resultados posibles:

- horas adicionales;
- tareas desplazadas;
- riesgo de incumplimiento;
- días sobrecargados;
- impacto sobre salud y objetivos.

## Modelo personal

AURA podría aprender:

- horarios de mayor concentración;
- duración real de tareas similares;
- frecuencia de interrupciones;
- tiempo necesario entre contextos;
- patrones de postergación;
- límites sostenibles de carga.

## Predicción de duración

Comparar duración estimada y duración real.

AURA podría recomendar estimaciones más realistas a partir del historial.

## Energía y recuperación

Usar datos manuales o externos para sugerir, nunca imponer, cambios en el plan.

Posibles fuentes:

- Garmin;
- Apple Health;
- Google Health Connect;
- Fitbit;
- entrada manual.

Configuraciones posibles:

- solo mostrar información;
- sugerir cambios;
- permitir replanificación automática.

## Actividades verificadas automáticamente

Ejemplos:

- ejercicio detectado por un reloj;
- reunión completada en el calendario;
- commit asociado a una tarea;
- entrega enviada;
- sesión de estudio registrada.

El sistema podría completar automáticamente tareas con alta confianza o pedir confirmación cuando exista duda.

Caso de uso:

Actividad detectada:

Resultado:
