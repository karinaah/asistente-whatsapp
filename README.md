# Asistente Inteligente por WhatsApp

Proyecto personal para construir un asistente basado en IA que permita:

- Recibir mensajes de voz por WhatsApp.
- Organizar automáticamente las tareas.
- Crear eventos en Google Calendar.
- Recordar hábitos y tareas.
- Aprender preferencias del usuario.

## Tecnologías

- Python 3.11
- FastAPI
- OpenAI
- WhatsApp Cloud API
- Google Calendar API
